# AI 메모지 웹앱 (가칭: 책갈피 메모)

화면 가장자리에 책갈피처럼 접혀 있다가, 누르면 펼쳐지는 바탕화면 메모지입니다.
모니터 옆에 붙여 두던 포스트잇을 화면 안에서 정리하고, 정리가 필요할 때 **AI 정리** 버튼 한 번으로 요약·일정·알람까지 잡아줍니다.

> **현재 단계: 기획 + 클릭 가능한 프로토타입.** 앱 코드는 아직 없습니다. 기술 스택은 [결정 필요 사항](docs/DECISIONS.md)에서 확정합니다.

## 핵심 아이디어

- **책갈피 탭**: 접힌 상태에서는 메모마다 키워드만 보여서 작업 화면을 가리지 않습니다.
- **펼치면 바로 메모**: 글, 사진, 스티커를 함께 붙일 수 있습니다.
- **AI 정리 버튼**: 사용자가 누를 때만 실행됩니다. 큰 키워드, 요점, 일정을 뽑고 확인 후 알람을 등록합니다.
- **스타일 선택**: 스크랩북 컨셉의 메모지 스타일을 고를 수 있습니다.
- **Mac · Windows 모두 사용**: 웹 기술로 만들고 Electron 또는 Tauri로 데스크톱 앱으로 포장합니다.

## 기능 로드맵 (요약)

| 단계 | 내용 |
| --- | --- |
| 1차 (MVP) | 책갈피형 메모지, 메모 작성, 이미지 첨부, AI 정리(요약), 일정 추출 + 알람 |
| 2차 | 회의 녹음 정리, 노션 업로드, 날씨 브리핑 |
| 이후 | 테마·구독 커스텀, 구글 캘린더 등 연동 |

자세한 내용은 [PRD](docs/PRD.md)와 [로드맵](docs/ROADMAP.md)을 보세요.

## 프로토타입 열어보기

`prototype/index.html` 파일을 브라우저로 열면 됩니다. 서버나 설치가 필요 없습니다.

1. 화면 왼쪽 가장자리의 책갈피 키워드를 눌러 메모지를 펼칩니다.
2. `+ 새 메모`를 눌러 `내일 오후 3시 치과 예약`처럼 적고 **AI 정리**를 누릅니다.
3. 아래쪽 `일정` 책갈피에서 `5초 뒤 알람 체험`을 눌러 알람이 울리는 모습을 봅니다.
4. 메모지 아래의 색깔 점 6개로 스타일을 바꾸고, `사진`·`스티커`로 꾸밉니다.

알아둘 점:

- 데이터는 브라우저의 `localStorage`에만 저장됩니다. 브라우저를 바꾸면 보이지 않습니다.
- 이 프로토타입의 **AI 정리는 실제 AI가 아니라 규칙 기반 간이 분석**입니다. 실제 AI 연결은 [AI 명세](docs/AI_SPEC.md)를 따라 앱 개발 단계에서 붙입니다.
- 글꼴(Jua, Gaegu, Gowun Dodum)은 인터넷에 연결되어 있을 때 적용됩니다.
- 화면 가장자리에 항상 붙어 있는 창, 단축키 호출, 시스템 알림은 웹 페이지로 만들 수 없어서 데스크톱 앱 단계에서 구현합니다.
