# CLAUDE.md

이 파일은 Claude Code가 이 레포에서 작업할 때 따르는 프로젝트 규칙입니다.

## 프로젝트

AI 메모지 웹앱(가칭: 책갈피 메모). 화면 가장자리에 책갈피 탭으로 접혀 있다가 클릭하면 펼쳐지는 바탕화면 메모지이고, 사용자가 **AI 정리** 버튼을 누르면 요약·일정·알람을 잡아준다. Mac과 Windows 모두에서 쓰는 것이 목표다.

## 현재 상태

- 기획 단계다. 앱 코드는 아직 없다.
- `prototype/index.html`은 화면과 동작을 확인하기 위한 단일 파일 프로토타입이다. 제품 코드가 아니며, 앱을 만들 때 그대로 가져다 쓰기보다 **화면 구조와 동작의 기준**으로 참고한다.
- 기술 스택은 확정되지 않았다. PRD의 제안은 React + Electron 또는 Tauri이다. 확정 전에는 임의로 프레임워크나 빌드 도구를 도입하지 않고, 필요하면 먼저 `docs/DECISIONS.md`의 D-01을 확인한다.

## 명령어

앱 스캐폴딩 전이라 빌드·실행·테스트 명령어가 아직 없다. 생기면 이 자리에 적는다. 명령어를 추측해서 적지 않는다.

프로토타입은 `prototype/index.html`을 브라우저로 열면 된다.

## 제품 규칙 (PRD에서 온 것, 어기지 않는다)

- AI는 사용자가 **AI 정리 버튼을 눌렀을 때만** 실행한다. 메모를 쓰는 중에 자동으로 AI를 호출하지 않는다.
- AI가 찾은 일정은 **사용자가 확인한 뒤에만** 알람으로 등록한다.
- 녹음을 시작할 때는 참석자 동의가 필요할 수 있다는 안내 문구를 보여준다.
- 평소 상태(접힘)에서 작업 화면을 가리지 않는다.

## 코딩 규칙

- 화면에 보이는 글자는 한국어로 쓴다. 코드 식별자는 영어, 주석은 한국어로 써도 된다.
- 사용자가 입력한 글(메모, 제목, AI 응답 포함)은 HTML로 해석하지 않는다. `textContent`를 쓰거나 이스케이프한다.
- API 키, 토큰은 화면(렌더러) 코드에 넣지 않는다. 앱 내부(메인 프로세스) 또는 서버에서만 쓰고, 값은 `.env`에 둔다. `.env`는 커밋하지 않는다. 필요한 키 이름은 `.env.example`에 적는다.
- 키보드로 모든 기능을 쓸 수 있어야 하고, 포커스 표시를 지우지 않는다. 움직임은 `prefers-reduced-motion`을 존중한다. (기준은 `docs/DESIGN.md`)
- 날짜와 시간은 사용자의 로컬 시간대로 다룬다. AI에 상대 날짜(내일, 금요일)를 해석시킬 때는 현재 시각을 함께 보낸다.
- 사진은 저장 전에 줄인다. 프로토타입은 긴 변 640px의 JPEG로 줄인다.

## 작업 방식

- `main`에 바로 푸시하지 않고 브랜치에서 작업한 뒤 PR을 연다. 규칙은 `CONTRIBUTING.md`를 따른다.
- 한 번에 한 가지 일만 바꾸고, 변경한 이유를 커밋 메시지에 적는다.
- 기능을 바꾸면 `docs/PRD.md`, `docs/DESIGN.md`, `docs/AI_SPEC.md` 중 해당 문서도 같이 고친다.
- 시크릿이 들어 있을 수 있는 파일(`.env`, 키 파일)은 읽거나 출력하거나 커밋하지 않는다.
