## D-01. 앱 형태: Electron 또는 Tauri

**배경**: PRD는 "웹(React)으로 만들고 Electron 또는 Tauri로 감싼다"까지만 정했습니다. 화면 가장자리에 붙는 창, 항상 위에 표시, 시스템 알림은 순수 웹으로 만들 수 없습니다.

| | Electron | Tauri |
| --- | --- | --- |
| 쓰는 언어 | JavaScript/TypeScript만 | 화면은 JS, 창·알림 같은 시스템 기능은 Rust |
| 설치 파일 크기 | 큰 편 (수십~100MB 이상) | 작은 편 |
| 팀 학습 부담 | 낮음. 웹 개발 지식으로 대부분 가능 | Rust를 한 사람이 맡아야 함 |
| 자료와 예제 | 많음 | 상대적으로 적음 |

**제안**: 팀에 Rust 경험자가 없으면 Electron으로 시작합니다. 메모 앱은 크기보다 빨리 만들어서 검증하는 것이 중요합니다. 화면 코드를 앱 형태와 분리해 두면 나중에 바꿀 수 있습니다.

**상태**: 미정

## D-02. 접힌 상태에 무엇을 보여줄까

- **PRD**: 화면 왼쪽 끝에 얇은 책갈피 탭 하나. 오늘 일정 개수 정도만 표시.
- **프로토타입**: 메모마다 책갈피 탭이 하나씩 있고, 탭에 그 메모의 **큰 키워드**와 다음 알람 시각이 보입니다. 맨 아래 `일정` 탭에 예정 일정 개수가 보입니다.

원래 아이디어("숨겨져 있을 때는 키워드만 보인다")는 프로토타입 쪽에 가깝습니다. 메모가 많아지면 탭이 길어지는 문제가 있어서, 탭이 너무 많을 때의 처리(스크롤, 최근 N개만 표시 등)를 정해야 합니다.

**제안**: 프로토타입 방식으로 PRD를 고칩니다.

**상태**: 미정

## D-03. 책갈피 위치

- **PRD**: 화면 왼쪽 끝.
- **프로토타입**: 왼쪽·오른쪽 전환 가능. 레포에 넣은 버전은 기본값을 왼쪽으로 맞췄습니다.

운영체제마다 화면 끝에 이미 뭔가 있습니다. Windows는 작업 표시줄이 아래쪽이라 좌우가 비어 있고, Mac은 Dock이 설정에 따라 왼쪽·오른쪽에 있을 수 있어서 겹칠 수 있습니다.

**제안**: 기본은 왼쪽, 설정에서 오른쪽으로 바꿀 수 있게 합니다.

**상태**: 미정

## D-04. 메모지 스타일 개수와 무료·구독 구분

- **PRD**: 기본 테마 3종(무료, 메모 색깔 + AI 비서 모습이 세트). 구독하면 색, 비서 모습, 배경, 글꼴을 하나씩 직접 바꿈.
- **프로토타입**: 스크랩북 스타일 6종(클립 색, 종이 모양, 뒷종이, 장식 세트)을 모두 선택할 수 있습니다. AI 비서 캐릭터는 아직 없습니다.

정해야 할 것: 무료는 3종인지 6종인지, 나머지 3종을 구독 상품으로 둘지, "AI 비서 모습"을 어떤 형태로 보여줄지.

**상태**: 미정

## D-05. AI 서비스와 API 키 보관 방식

PRD는 "LLM API"와 "키는 화면 코드에 넣지 않는다"까지만 정했습니다.

정해야 할 것:

- 사용할 AI 서비스와 모델 (비용, 응답 속도, 한국어 날짜 해석 정확도로 비교)
- 키를 **사용자가 직접 입력**(설정 화면의 API 키 입력)하는지, **팀이 서버를 두고 대신 호출**하는지. 사용자 입력 방식은 서버가 필요 없지만 일반 사용자에게는 진입 장벽이 큽니다. 서버 방식은 구독 모델과 맞지만 서버 운영과 비용이 생깁니다.

**제안**: MVP는 사용자 입력 방식으로 시작하고, 구독을 열 때 서버 방식을 검토합니다.

**상태**: 미정

## D-06. 저장 방식

PRD: "내 컴퓨터에 우선 저장, 필요 시 서버 DB".

프로토타입은 브라우저 `localStorage`에 저장하고, 사진은 긴 변 640px JPEG로 줄여 메모 안에 함께 넣습니다. 이 방식은 용량 한도(보통 5MB 안팎)가 있어서 사진이 많으면 꽉 찹니다. 앱에서는 로컬 파일 또는 SQLite 같은 저장소가 필요합니다.

**상태**: 미정

## D-07. 스티커 기능

사진과 별·하트·리본 같은 스티커를 메모지에 자유롭게 붙이는 기능이 프로토타입에 있지만 PRD에는 없습니다. (PRD의 이미지 첨부는 붙여넣기·끌어놓기)

**제안**: P1로 PRD에 추가합니다. 메모지를 꾸미는 재미가 스타일 선택과 함께 이 앱의 차별점입니다.

**상태**: 미정

## D-08. 규칙 기반 자동 제안

PRD는 "정리는 AI 정리 버튼을 누를 때만, 자동 실행 아님"이라고 정했습니다. 프로토타입에는 AI가 아닌 규칙 기반 동작이 두 가지 있습니다.

1. 메모를 닫을 때 키워드가 비어 있으면 간단한 규칙으로 키워드를 채웁니다.
2. 메모에 "금요일 오후 2시"가 있으면 `+ 알람` 제안 칩을 점선으로 보여주고, 눌러야 등록됩니다.

둘 다 AI를 호출하지 않고 알람도 자동 등록하지 않습니다. PRD의 "자동 실행 아님" 원칙과 충돌하지 않는지 팀이 확인해야 합니다.

**상태**: 미정
