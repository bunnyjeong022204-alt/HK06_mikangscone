# 디자인 가이드

화면 동작과 메모지 스타일의 기준입니다. `prototype/index.html`에서 실제 동작을 볼 수 있습니다. 확정되지 않은 부분은 [DECISIONS.md](DECISIONS.md)를 보세요.

## 컨셉

컴퓨터 밖에 붙여 두던 포스트잇을 화면 안으로 가져온 느낌입니다. 클립으로 집은 종이, 깅엄 체크 뒷종이, 별·하트·리본 스티커처럼 **스크랩북** 같은 따뜻한 질감을 씁니다.

글꼴은 세 가지를 역할별로 씁니다.

| 쓰임 | 글꼴 |
| --- | --- |
| 큰 키워드, 책갈피 탭 | Jua |
| 메모 본문 (손글씨 느낌) | Gaegu |
| 버튼, 안내문 등 화면 글자 | Gowun Dodum |

## 책갈피 탭

| 상태 | 모습 |
| --- | --- |
| 접힘 | 화면 가장자리에 탭 끝부분이 살짝 가려진 채로 붙어 있고, 키워드와 다음 알람 시각이 보인다 |
| 마우스를 올림 / 키보드 포커스 | 탭이 전부 나와서 글자가 온전히 보인다 |
| 열림 | 해당 탭이 안쪽으로 조금 당겨지고, 옆에 메모지가 펼쳐진다 |
| 알람 울림 | 탭이 좌우로 흔들리고, 화면 위쪽에 알림 카드가 나온다 |

- 탭 색은 메모 스타일의 클립 색을 따른다.
- 맨 위에 `+ 새 메모`(점선 탭), 맨 아래에 `일정`(어두운 탭)이 있다.
- 메모지 바깥을 누르거나 `Esc`를 누르면 접힌다. 메모지 아래의 `>` 버튼으로도 접을 수 있다.
- 비어 있는 새 메모는 접을 때 자동으로 사라진다.
- 키워드가 비어 있는 메모는 탭에 `새 메모`라고 보인다.

## 메모지 구성 (위에서 아래로)

1. 큰 키워드 (최대 8자, 형광펜 밑줄)
2. 제목 (선택)
3. AI 요점 (AI 정리를 눌렀을 때만 표시)
4. 본문 (줄 노트 느낌)
5. 사진 (메모당 최대 4장, 마우스를 올리면 `스티커로 붙이기`·`삭제`)
6. 알람 칩 (등록된 알람은 실선, 등록 가능한 제안은 점선)
7. 스티커 층 (본문 위에 자유롭게 놓임)

메모지 아래 도구 막대: `접기`, `사진`, `스티커`, `AI 정리`, 스타일 선택 점 6개, `삭제`(한 번 더 눌러야 삭제).

- 스타일을 바꿔도 글과 사진은 그대로 유지된다.

## 스티커

종류: 은색 별, 세이지 별, 은색 하트, 크림 하트, 핑크 리본, 체크 리본, 왁스 씰, 별 단추, 마스킹 테이프, 그리고 **내 사진**.

- 끌어서 옮기고, 누르면 `작게`·`크게`·`돌리기`·`떼기` 막대가 나온다.
- 메모 안의 사진을 `스티커로 붙이기`로 바꾸면 하얀 테두리가 있는 사진 스티커가 된다.

## 사진 넣는 방법

`사진` 버튼, 메모지 위로 끌어놓기, 본문에서 붙여넣기(`Ctrl+V` / `Cmd+V`). 저장 전에 긴 변 640px로 줄인다.

## 일정 화면

- 위쪽: 오늘 일정 개수와 다음 알람까지 남은 시간을 한 줄로 알려주는 브리핑.
- 목록: 오늘 / 내일 / 앞으로 / 지난 일정으로 나눈다. 각 줄에서 완료 체크, 알람 켜기·끄기, 반복(한 번·매일·매주), 삭제를 할 수 있고, 제목을 누르면 그 메모가 열린다.
- 아래: `메모에서 일정 모두 찾기`, `5초 뒤 알람 체험`.

## 접근성 기준

- 모든 버튼은 키보드로 누를 수 있고, 포커스를 받으면 빨간 윤곽선이 보인다.
- 아이콘만 있는 버튼에는 `aria-label`을 단다.
- `prefers-reduced-motion`이 켜져 있으면 애니메이션을 끈다.
- 알람 알림은 색이나 흔들림만으로 전달하지 않고 글로도 보여준다.
- 사용자가 쓴 글은 `textContent`로만 넣는다.
