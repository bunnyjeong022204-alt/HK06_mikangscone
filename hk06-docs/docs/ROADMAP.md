## 1단계. MVP (1차)

PRD 1차 범위: 책갈피형 메모지 + 메모 + 이미지 + AI 정리 요약 + 일정·알람

**준비**

- [ ] 앱 형태 확정 후 프로젝트 스캐폴딩 (D-01)
- [ ] 실행·빌드 명령어를 `README.md`와 `CLAUDE.md`에 적기
- [ ] 저장소(로컬 저장) 방식 정하고 메모 데이터 구조 확정 (D-06)

**기능**

- [ ] P0 책갈피형 메모지: 가장자리에 붙은 창, 클릭으로 펼침·접힘
- [ ] P0 메모 작성·수정·삭제, 스타일(색) 선택
- [ ] P0 이미지 첨부: 붙여넣기, 끌어놓기
- [ ] P0 AI 정리 버튼: 요약, 키워드, 할 일 추출 ([AI 명세](AI_SPEC.md))
- [ ] P0 AI 일정 추출 + 확인 후 알람 등록
- [ ] 설정 화면: API 키 입력 (D-05)
- [ ] 시스템 알림 (앱이 뒤에 있어도 알람이 보이게)

**확인**

- [ ] Mac, Windows 양쪽에서 설치하고 실행해 보기
- [ ] [AI 명세](AI_SPEC.md)의 예시 메모 5개로 일정 추출 결과 비교
- [ ] AI 응답이 깨지거나 인터넷이 없을 때의 동작 확인
